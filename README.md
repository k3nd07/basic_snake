** Classic Snake Game (Tkinter)

A classic Snake desktop game built with Python and Tkinter. It features responsive controls, adaptive speed scaling, persistent high-score tracking, and supports multiple keyboard layouts out of the box.

✨ Features

Dual Keyboard Layout Support: Works seamlessly with standard Arrow keys or WASD in both English and Cyrillic (RU) keyboard layouts.

Dynamic Speed: The game speeds up as your score increases to keep gameplay challenging.

Persistent High Score: Saves your highest score locally to snake_record.txt.

Pause & Restart Controls: Easily pause at any moment or quickly restart after a loss.

Zero External Dependencies: Built entirely using Python's standard tkinter library.

🛠️ Requirements

Python 3.x

Tkinter (included by default with Python on Windows and macOS; linux users can install via sudo apt-get install python3-tk).

🚀 Quick Start

Clone the repository:

git clone https://github.com/your-username/snake-game.git
cd snake-game


Run the game:

python 1_snake_game.py


🎮 How to Play

Move: Arrow Keys or WASD / ЦФЫВ

Pause / Resume: Spacebar

Restart Game: R / К

Eat the red food to grow longer and increase your score. Be careful not to hit the boundaries or collide with your own tail!

📁 File Structure

1_snake_game.py — Main game logic and GUI application.

snake_record.txt — Local file created automatically to persist your high score**
